# Single-Game Ticket Purchasing Trends Analysis - Atlanta Braves (2023–2026)

## About

Analyzed multi-season single-game ticket purchasing behavior for the Atlanta Braves to answer the question: **"Are fans buying tickets closer to game day compared to prior seasons?"**

The analysis combined three data sources across four seasons:
- **Primary site traffic** - Ticketmaster event detail page clickstream (visitors, visits, hits)
- **Secondary market traffic** - SeatGeek event page views and checkout activity
- **Single-game ticket sales** - Transaction-level data (seats sold, revenue, buyer counts)

Built for the Braves' revenue and ticketing leadership to inform pricing strategy and promotional timing.

> **Note:** This repository uses **synthetic data** that preserves the analytical patterns and findings from the original analysis. No proprietary team data is included. The R scripts, SQL logic, visualizations, and methodology are authentic.

---

## Key Findings

1. **Volume is up across the board** - 2026 has the highest single-game seats sold in every purchase-timing window (day-of, 1–2 days out, 3–7 days, etc.)
2. **Conversion rates are improving** - Transactions per primary site hit increased year-over-year, with 2026 showing the strongest conversion at every time horizon
3. **Timing mix is stable** - Despite higher volume, the proportional split of *when* fans buy has not meaningfully changed; the extra volume is distributed proportionally across all windows, not concentrated in any one bucket
4. **Primary traffic rebounded** - Site traffic dipped in 2025 but recovered in 2026; secondary market traffic has declined each year
5. **Consistent across tiers** - Both higher-tier games (Diamond/Marquee/Premier) and lower-tier games (Select/Standard/Value) show the same stable timing distribution

See [findings.md](findings.md) for a deeper write-up.

---

## Methodology

- **Day-bucket analysis** - Bucketed site traffic and ticket sales by days before game (Day of, 1–2 days, 3–7 days, 8–21 days, 21+ days)
- **YTD normalization** - Compared year-to-date averages across seasons to control for schedule differences
- **Conversion efficiency** - Calculated single-game transactions per primary site hit, both overall and by game tier
- **Lead-time distribution** - Used a weighted median of purchase lead time (weighted by seats sold) to compare continuous distributions between seasons
- **Tier segmentation** - Joined game-tier classifications (based on opponent and day-of-week pricing) to analyze whether purchase timing varies by game desirability

## How to Run

**Prerequisites:** R with packages `ggplot2`, `dplyr`, `tidyr`, `scales`

```r
install.packages(c("ggplot2", "dplyr", "tidyr", "scales"))
```

**Steps:**

1. **Generate synthetic data**
   ```bash
   Rscript scripts/generate_synthetic_data.R
   ```
   Creates CSV files in `data/`.

2. **Run the analysis**
   ```bash
   Rscript scripts/purchase_trends_analysis.R
   ```
   Generates all 11 plots in `graphs/`.
